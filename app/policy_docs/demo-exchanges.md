## section: exchanges
### Exchanges

Within the same **30-day** demo return window, customers may request an exchange for the **same item** in a different size or color when inventory is available in the simulated catalog. Price differences may apply. Exchanges follow the same authorization steps as returns. This policy does not guarantee stock or complete an exchange automatically.
